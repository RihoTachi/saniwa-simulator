## 运行方式（推荐）

### Windows
双击 `启动游戏.bat`，浏览器打开 `http://127.0.0.1:8000`。

### Android / macOS / Linux
安装 Python 3 后，在本目录执行：

```bash
python -m http.server 8000
```

然后浏览器打开 `http://127.0.0.1:8000`。PWA 离线缓存需要通过 localhost 或 HTTPS 运行；直接双击 HTML 也能看界面，但部分本地世界书检索与离线功能会受浏览器限制。

## API 设置

打开右上角「菜单」→「AI / API 配置」。支持 GPT / OpenAI 兼容端点、DeepSeek、Claude、Gemini 以及自定义 OpenAI 兼容端点。API Key 只保存在当前页面内存，不写入本地存档。浏览器直连并不能彻底保护密钥；长期在线部署建议加入后端代理，并设置服务端密钥管理、速率限制和访问控制。

不同服务商可能因 CORS、账号权限或模型接口版本而拒绝浏览器直连；这不一定代表密钥错误。在线部署时建议使用 HTTPS。

## BGM
默认曲目《花の薫りは叶枝垂れ》纯音乐版已内置为 `assets/default-bgm.mp3`。资料库中的 `audio.mp3` 实际是 AAC 音频封装在 MP4 容器中、只是扩展名写成 MP3；已确认可解码，并转换为标准 MP3 供浏览器播放。浏览器通常要求用户先进行点击等交互后才允许播放，因此游戏会在开始新游戏或继续游戏的用户操作中尝试启动音乐；若浏览器仍拦截，可在「游戏设置 → 背景音乐」手动播放。单文件版会内嵌音频。官方音乐页面快捷入口保持移除。
